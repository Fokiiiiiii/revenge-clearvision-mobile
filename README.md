# ClearVision Mobile

Revenge Next用のカスタムCSSテーマ。設定はCSS欄のみ。409種類のテーマ色と、角丸・余白の28項目を実機APIへ対応付けています。[CSSリファレンス](docs/css-reference.md) と [Fuji Night CSS](presets/fuji-night.css) を参照してください。

インストール用Repository URL: https://raw.githubusercontent.com/Fokiiiiiii/revenge-clearvision-mobile/main/plugin-dist

v1.0.1のテスト26件・型チェック・ビルドを確認しました。配布版の全画面表示は実機確認中です。

Independent JavaScript-only plugin repository for Revenge Next on Android.

Build with Bun: bun install, then bun run build. The JS bundle is generated under plugins/clearvision-mobile/build/js/.

The plugin uses Revenge's mobile API and dynamic module lookup. Device-runtime compatibility remains pending recovery of the connected Discord APK.
